## Implementation và self-review

Page compose Active/Recent/Catalog views; mỗi view dưới200 lines, không API call.
`use-dashboard` chọn current/recent và điều phối hai snapshots; helper feature
`use-dashboard-snapshot` dùng TanStack Query, hai capability PlatformApi có sẵn.
History GET thuộc Assessment, không Reporting; Catalog browse vẫn thuộc Catalog.
Không import feature Results internals hoặc backend implementation. Pure model
map room/result/status paths và exact owner/version frozen title.

History là page1 tối đa20, current là first CREATED/IN_PROGRESS trong snapshot;
recent là tối đa3 lượt khác, không là toàn bộ lịch sử hoặc tổng số lượt đang thi.
Catalog là page1 tối đa3 theo category, không recommendation/personalization.
Cursor null không nói có trang sau; điểm null không phải0. Không dùng current
Catalog title cho attempt phiên bản cũ, không phát thêm GET từng row chỉ để có
title/timer/progress. Explicit detail navigation có thể populate đúng frozen
metadata, còn title chưa biết dùng suffix phiên bản và link đúng attempt.

Keys gồm resource/Dashboard/actor/local epoch/filter. Session loading/unavailable/
anonymous/reauth ẩn cả hai nguồn và purge.401/403 latch/purge riêng channel,
không auto retry; channel còn được phép vẫn độc lập. Real live adapter/session
owns auth recovery; controller không suy global permission từ snapshot. Actor/
epoch đổi hủy scope cũ, xóa metadata; unmount cancel/remove scoped cache.
Query signal kiểm trước/sau I/O và catch: PlatformApi chưa abort network call,
nhưng late outcome không restore private cache hoặc thay đổi clock/denial.

Transient lỗi giữ snapshot đã nhận, có warning "Dữ liệu từ lần tải trước"; initial
load error khác empty. Refresh callbacks serialize từng channel, disable focus/
reconnect/default retry. Denial và monotonic Retry-After guard cập nhật ngay trong
catch trước React render: chained callbacks/category switch không bypass wait.
Retry clocks reset theo auth scope, không mang thời gian chờ tài khoản A sang B.
Không API polling; interval chỉ cập nhật countdown local khi có server wait.

Layout giữ selected Cobalt–Apricot/white shell/rail,2:1 desktop active/guide,
recent full-width,3 catalog cards. Tablet768px stack active/guide,2 catalog columns;
long title/name wrap, body greeting16px, helpers14px+, gutters24px, controls44px.
Không thêm fake claims hoặc boards trong raster. Existing narrow-screen checks
giữ nguyên, không mở mobile/app matrix.

`playwright.port-05g.config.ts` là local receipt configuration: reuse existing
base tests, tự bật/dừng hai preview, từ chối reuse server khác và ghi artifacts
vào increment này. Full run trước interruption chưa bắt đầu, không ghi thành
failed/skipped/PASS. Config adds no app behavior/dependency/AWS resource; chạy
