## Ownership and invariants

Catalog feature owns query controllers, local search and start interaction. Views
use shared UI; injected PlatformApi remains the transport boundary. Backend
Catalog/Assessment remain authoritative for publication, ownership, limits,
server time, frozen attempt and durable start receipt. No API/schema/AWS changes.
Start request body remains absent: frontend cannot promise that its preview locks
the publication before POST. Accepted response selects the actual attempt ID.

Read list uses server category + pageSize/cursor. Search is local to loaded rows,
explicitly labeled; no global search/total/page number/remaining quota inferred.
Refresh restarts the first page and does not reuse expired cursors. Counts always
state loaded scope. No provider latency, proctor, certificates or enterprise tiers.

Start intent retains examId/key across unknown outcomes. Pending blocks duplicate
sends; cancel/close cannot claim to undo an accepted or unknown request. Determinate
4xx errors can release the intent; unknown outcomes only permit the same request.
Late completion after route/session/access change must not navigate or restore
private metadata. No official scoring at client and no questions/keys before start.
