# Logo tạm — ExamPlatform

Biểu tượng phiếu thi trắng trên nền Cobalt, góc giấy Apricot. Dùng cùng hệ màu của Dashboard V2/V3; phần chữ tên sản phẩm đơn giản để giữ độ rõ ở header.

- [Mark SVG](examplatform-mark.svg): rail, avatar sản phẩm, favicon; tỷ lệ vuông, kích thước tối thiểu đề xuất 24px.
- [Wordmark SVG](examplatform-wordmark.svg): public header; giữ tỷ lệ, không thêm một tên brand thứ hai bên cạnh.
- PNG cùng tên được render từ SVG để đính kèm vào Stitch khi cần. SVG là bản nguồn; không có remote image dependency.

Font wordmark ưu tiên Be Vietnam Pro, fallback Arial/sans-serif. Đây là logo tạm cho giai đoạn chốt UI, chưa phải bộ nhận diện thương hiệu chính thức. Tài sản được lưu cùng template; chưa thay logo trong ứng dụng đang chạy.
