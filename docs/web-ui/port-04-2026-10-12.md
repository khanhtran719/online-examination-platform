## Review implementation

- Feature Admin sở hữu `useReportPages`, Operations/BusinessMetrics/Attempt/Replay/
  Insights controllers. Pages chỉ trình bày state và phát hành thao tác; shared UI
  không import runtime/session/adapter. Cursor refresh bỏ chain cũ, đọc lại trang
  đầu; không chạy đồng thời load-more/refresh. Monitor chỉ poll khi tab visible.
- Adapter HTTP đọc đúng `/v1/admin/business-metrics`, độc lập technical permission.
  Parser kiểm allowlist, timestamps, count invariants, active metadata `asOf` và
  statistics `answered`. Combined legacy method chưa xóa vì không thuộc scope;
  UI mới không gọi nó. API source/migrations không đổi.
- Permission revoke và403 ẩn/xóa cache, hủy query và bỏ response cũ; version filter
  không reset forbidden latch. Audit drawer dùng row redacted đã tải; clipboard
  callback cũ không khôi phục notice sau đổi row hoặc mất quyền.
- Replay cần FAILED, chưa replayPending, reporting/replay permissions và nguồn
  admin revision hợp lệ. Dialog xác nhận reason8–500 Unicode codepoints; gửi lặp
  bị chặn đồng bộ. Unknown retry giữ nguyên key/body, không tự retry. ACK không
  được hiển thị thành completed. Live vẫn chặn khi thiếu admin revision/capability.
- Multiple-choice bars có denominator là completed attempts cho từng lựa chọn;
  tổng selections có thể lớn hơn số bài. Zero sample không bị trình bày như0%.
