## Ownership và contract

`features/profile` sở hữu controller và views; `app/session` cung cấp principal
projection/logout/adoption. Chỉ `getProfile` và `updateProfile` qua PlatformApi
hiện có; email/verification read-only, displayName 1–80 Unicode code points,
leaderboard opt-in và expectedRevision. Không endpoint/dependency/AWS resource.
API Identity/PostgreSQL sở hữu authorization, transaction, revision, receipt
và audit. Không profile permissions/token decoding, avatar upload, email/password
change, magic-link/GitHub control giả, certificates/proctoring/latency giả.

Giữ request immutable trong mounted controller, explicit retry không tự sửa
expectedRevision. Success receipt khác refreshed current projection; read lỗi
sau receipt không được gọi write thất bại hoặc POST lại.409 cần snapshot mới
và lựa chọn rõ ràng trước đổi revision; không force overwrite.401/403 hoặc
actor/session loss ẩn/xóa private state và bỏ late response. Navigation/native
unload/logout phải nói đúng về profile draft và unknown outcome.

## Implementation và self-review

Page compose identity/settings/session/dialogs; `use-profile.ts` sở hữu finite
remote write/read coordinator, scope và sync busy guards. Model validation dùng
Unicode code points/control characters. Fields freeze pending/unknown/conflict;
trim tên tại capture. DOM limit160 UTF-16 units vẫn cho phép80 astral code points.
Native checkbox tách accessible name và description/privacy status. Không tự cấp
leaderboard eligibility hoặc đổi email/password tại Profile.

Một UUIDv7/body/expectedRevision cho mỗi logical write. Unknown network/timeout/
malformed/unavailable/5xx/429 giữ intent cho explicit retry và honor Retry-After
bằng monotonic time; không auto POST. ACK phải đúng actor và baseRevision+1.
Receipt-confirmed fields khác current projection: GET lỗi sau ACK không POST
lại. Current projection không được thấp hơn revision đã quan sát, hoặc khác
acknowledged fields ở cùng revision. Protected401/403/404 latch/clear local;
actor/reauth/unmount fence bỏ late response. PlatformApi chưa abort I/O đang chạy;
fence không hủy mutation đã gửi. Profile reauth xóa local intent/draft và cần đọc
lại sau login; không hứa giữ như Exam Room.

409 giữ local/base, tải snapshot mới. Read lỗi/pending không cho chọn. Dùng bản
máy chủ bỏ draft; giữ bản của tôi đưa draft về form với revision vừa đọc và còn
phải bấm lưu tạo intent mới. Race sau read vẫn do API optimistic concurrency
chặn; không auto-merge/force overwrite. Dirty draft không ngầm theo revision mới
trong session. `app/session.syncProfile` chỉ same actor/email và monotonic revision,
không login/confirm refresh/replace actor như `adoptProfile`.

Profile local dialogs reset theo actor/auth scope. Router blocker/native unload,
