AWS resource is authorized by this port. Live Admin remains capability-blocked.

Use the selected [design contract](templates/codex-desktop-v1/design-contract.md)
and Editor briefs/images. Dates retain the selected timezone and instant; minutes
map to integer durationSeconds (including existing second precision). Read/write
fields follow the existing API, not invented controls from the raster.

Save acknowledgement and publish acknowledgement are separate. An unconfirmed
write retains its immutable key/body and continuation; retrying publication must
not save the draft again. Pending/unknown writes block competing operations.
Conflicts retain local edits until explicit replacement by a freshly read draft.
Remove-section changes only local membership; archive/unpublish preserve attempts.
Unsaved navigation warns; no offline recovery or autosave claim.

## Inspection findings

The inspected editor retained local fields across steps and froze individual request
intents. Unpublish/leave/remove-section confirmation and conflict choices were missing.
Save→publish retry restarted save after an unknown publish; two separate
intent machines did not guard competing operations. Duration validation rejected
valid integer-second durations unless divisible by60. Non-finite points and empty
section names were not rejected locally. Shared dialog reinitialized focus whenever
an inline onClose changed; disabled-only dialog could not contain Tab. Failing
regressions preceded behavior fixes.

## Implementation decisions

Editor model validates local completeness (including a question per section),
Unicode title limits, independent schedule/structure errors and finite integer
points. This intentionally retains the existing editor's stricter completeness
UX; backend draft APIs still allow incomplete drafts and are unchanged. Minute
inputs round-trip integer seconds; untouched source schedule instants retain
seconds/milliseconds and DST occurrence. Changing timezone updates both display
fields atomically while preserving UTC. The source schedule is local metadata,
never an extra request field.

One controller-owned operation spans save→publication. It freezes stage/key/body,
blocks competitors, records save acknowledgement before publication, and resumes
only the unconfirmed stage. Network/timeout/malformed/5xx remain ambiguous;
unknown copy does not report definitive failure. A409 Version conflict fetches a
fresh projection without replacing local fields. Only explicit adoption replaces
fields and revision. A403 write/read hides and clears protected query/local data.
Archived inputs/actions are read-only. Reporting links require reporting.read.

Information/structure/preflight and actions/dialogs remain feature-owned views;
shared Dialog owns stable focus containment, Escape, close and trigger restoration.
Only the upper dialog traps focus/handles keys when an asynchronous warning opens
over an existing question sheet; a red regression reproduced the focus collision.
No UI/state library or backend layer is added. Internal route blockers preserve
edits until discard; native beforeunload handles reload/close. Drafts remain
memory-only; session clearing still overrides recovery. Full logout-warning/session
integration and the complete mobile/state matrix remain separate gates.

Synthetic DemoApi Catalog create/replace/publish now consume the existing bounded
fault presets to exercise browser pending/lost-ACK/conflict recovery. Receipts
still prevent duplicate mutations. These scenarios are explicitly synthetic,
excluded from the live build, and make no backend resilience claim.

## Review outcome and reference differences

The three-step editor uses the selected Cobalt–Apricot typography, compact
header, numbered steps, white rounded cards, 2:1 form/summary layout and distinct
confirmation/recovery dialogs. Actual session identity, API policies and loaded
bank content replace raster placeholders. Native combined date/time inputs retain
keyboard entry and second precision instead of imitating separate raster controls.
Preflight totals/checklist use local fields, not static success indicators.

Unpublish confirmation is available from the editor. The EP-19 list-row action
menu and its raster background are outside this increment; this does not accept
the complete list-row action matrix. No unsupported bell, proctoring, reporting
counter, automatic merge or forced revision override was added.

Self-review fixes include unknown publication retry restarting save, competing
operations, create-receipt hydration overwriting edits, unavailable bank/read/write
data retention, publication continuation after permission revoke, integer-second
duration precision, invalid/DST-gap dates, UTC milliseconds/DST-occurrence loss,
timezone changes, stale success copy in a new operation, disabled/layered dialog
focus and comparison text overlapping columns. Source/query/receipt ownership
remains within the documented feature/controller/shared boundaries.
