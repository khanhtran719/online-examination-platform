# SY-07 — Xác nhận lý do xử lý lại

## Mô tả chức năng và phong cách

Overlay target theo Assessment ReplayRequest, dùng đúng nền EP-29 …0081. Điều kiện để mở/bật confirm: FAILED, quyền assessment.replay, reporting.read cho nền, revision quản trị hiện tại hợp lệ, lý do trim8–500 ký tự, intent chưa inflight. Live Web hiện thiếu nguồn revision nên EP-29 main disabled; dialog này **không phải state live mở được hiện hành**, không sửa nền để giả capability. Chỉ thêm overlay target trên bản copy ảnh EP-29 sau khi xem file nền.

Reason “Phụ thuộc đã được khôi phục; xử lý lại bài nộp gốc.” hợp lệ, replayPending=false và điểm null trên nền. Dialog centered trắng560px, khoảng520–600px, backdrop trung tính, close/cancel/primary rõ. Title “Yêu cầu xử lý lại”; summary mã lượt/version; required textarea đã điền; helper tối thiểu8 ký tự; thông điệp giữ nguyên answers/attempt và chỉ gửi yêu cầu. CTA enabled **chỉ trong target có đủ điều kiện**. Không accepted receipt hoặc grading success, không sửa điểm/answer/quota hay tạo lượt mới. Current-vs-target ghi ngoài product trong brief/manifest.
